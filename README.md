## 🌟 أقسام ومميزات التطبيق (Core Modules)

1. **اللياقة البدنية (Fitness):** خطط تمارين منزلية مخصصة حسب المستوى بدون إنترنت مع رسوم توضيحية خفيفة.
2. **التغذية الذكية (Nutrition):** حاسبة سعرات وماء محلية، ووصفات صحية بناءً على المكونات المتاحة في المنزل.
3. **الإنتاجية والتركيز (Focus & Habits):** مؤقت بومودورو مع أصوات بيضاء مولدة برمجياً، ومتعقب عادات يومية.
4. **الصحة النفسية (Mental Wellness):** تمارين تنفس تفاعلية، دفتر امتنان مشفر محلياً، وتحديات الديتوكس الرقمي.
5. **التعلم السريع (Learning):** بطاقات الحفظ بالتكرار المتباعد (Flashcards) ومكتبة اقتباسات يومية.
6. **الطوارئ (Emergency):** دليل إسعافات أولية سريع ومبسط للحالات الحرجة.
7. **التحفيز والتحديات (Gamification):** نظام أوسمة ومكافآت، ومشاركة التحديات وجهاً لوجه عبر مسح الـ QR Code.
